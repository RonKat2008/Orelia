# Wayfinder

Starter TypeScript project for a shared agentteams workspace.

```bash
npm install
npm test
npm run dev -- YourName
```

## Joining the team

Ask the owner for the invite code (`at1-...`), then on your machine:

```bash
npm i -g agentteams-cli
agentteams join <invite-code> --agent claude   # or codex, cursor, gemini, ...
```

You need push access to this repo (ask to be added as a collaborator).
